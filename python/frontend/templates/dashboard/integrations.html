Automation Platforms

Use post-call webhooks to pipe call data into your favourite no-code platforms.

M Make (Integromat) Setup

  1. 1Open Make → Create a new scenario
  2. 2Search for Webhooks → choose Custom webhook → click Add
  3. 3Copy the webhook URL Make provides and paste it into Agent → Integrations → Webhooks
  4. 4Add a JSON → Parse JSON module after the webhook trigger; map {{1.body}} as input
  5. 5Connect any action: Google Sheets, CRM, Slack, etc.

Example: Add row to Google Sheets

Add Google Sheets → Add a Row and map:

  • Call ID → {{1.call_id}}
  • Caller name → {{1.lead_data.name}}
  • Summary → {{1.summary}}
  • Sentiment → {{1.sentiment_label}}
  • Custom var → {{1.extracted_variables.YOUR_VAR}}

Z Zapier Setup

  1. 1New Zap → Trigger: Webhooks by Zapier → Catch Hook
  2. 2Copy the webhook URL and paste it into Agent → Integrations → Webhooks
  3. 3Click Test trigger in Zapier — VoiceFlow sends a sample payload automatically
  4. 4All fields auto-detected: call_id, summary, lead_data__intent_level (nested fields flattened with __)
  5. 5Add actions: HubSpot Contact, Slack message, email, Google Sheets row, etc.

Example: Create/Update HubSpot Contact

  • Phone → lead_data__phone
  • First Name → lead_data__name (use Zapier Formatter to split)
  • Lead Status → based on lead_data__intent_level
  • Note → summary

Example: Slack notification

New call from {lead_data__name} ({sentiment_label}) — {summary}

n n8n Setup

  1. 1New workflow → Add Webhook node; set HTTP method to POST
  2. 2Copy the production URL and paste into Agent → Integrations → Webhooks
  3. 3Add a Code node to verify the HMAC signature (see snippet →)
  4. 4Access fields via ${{ $json.body.call_id }}, ${{ $json.body.summary }}
  5. 5Use IF node + branch: interesting leads → CRM, others → spreadsheet

HMAC Verification (Code node)

const crypto = require('crypto');
const secret = 'your-webhook-secret';
const body = JSON.stringify($input.first().json.body);
const ts = $input.first().headers['x-voiceflow-timestamp'];
const sig = $input.first().headers['x-voiceflow-signature'];
const expected = crypto
  .createHmac('sha256', secret)
  .update(ts + '.' + body)
  .digest('hex');
if (expected !== sig) throw new Error('Invalid signature');
return $input.all();

G GoHighLevel Setup

After each call, VoiceFlow automatically syncs the contact and call data into GHL.

  1. 1Go to GHL → Settings → Integrations → API Keys → create a Location API Key
  2. 2Go to Settings → API Keys in VoiceFlow and paste the GHL API key (v2)
  3. 3Optionally enter a GHL Location ID to scope to a sub-account
  4. 4Optionally enter a Workflow ID — VoiceFlow will trigger this GHL automation after each call, passing lead data as payload
  5. 5Click Save All

What VoiceFlow syncs to GHL

  • Search contact by phone number (create if not found)
  • Update contact name, email if extracted
  • Add call note: summary + extracted variables + sentiment
  • Apply tags: voiceflow, call outcome, intent level
  • Trigger workflow with lead_data payload (if Workflow ID set)

Request headers

Content-Type: application/json
X-VoiceFlow-Signature: <hmac-sha256-hex>
X-VoiceFlow-Timestamp: <unix-epoch-seconds>

Python signature verification

import hmac, hashlib

def verify(body: bytes, timestamp: str,
           secret: str, signature: str) -> bool:
    payload = (timestamp + "." + body.decode()).encode()
    expected = hmac.new(
        secret.encode(), payload, hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(expected, signature)

Mid-Call Booking

Check availability and book appointments during the voice call using built-in tools.

C Cal.com

  1. 1Get API key from app.cal.com/settings/developer/api-keys
  2. 2Go to Agent → Integrations → Cal.com and paste the key
  3. 3Enter your Event Type ID (visible in event URL or GET /v2/event-types)
  4. 4The agent auto-calls check_calcom_availability and book_calcom_appointment when caller asks to book

G Google Calendar

  1. 1Create a Service Account in Google Cloud Console; grant it Editor on your calendar
  2. 2Download the JSON key file
  3. 3Paste the entire JSON into Agent → Integrations → Google Calendar → Service Account JSON
  4. 4Enter your Calendar ID (use primary or a specific ID)
